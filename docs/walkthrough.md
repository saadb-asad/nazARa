# NazARa - Project Walkthrough

**NazARa** is now fully implemented! This guide covers how to run the project, add items, and test the Augmented Reality experience.

## 1. Getting Started

### Run the Development Server
Open your terminal in the project directory (`/home/saad/Documents/NazARa`) and run:
```bash
npm run dev
```
Visit **[http://localhost:3000](http://localhost:3000)** in your browser.

---

## 2. Admin Dashboard (Restaurant Owner)

### Login
Since we haven't built a signup page (Restricted to Super Admin), you can bypass the login for testing or create a user in Supabase Authentication tab.
*   **Login URL**: `http://localhost:3000/admin/login`

### Adding an Menu Item
1.  Go to **Dashboard**: `http://localhost:3000/admin/dashboard`
2.  Click **"+ Add New Item"**.
3.  Fill in Name, Price, Description.
4.  **Upload a .glb file**: This is crucial. (You can find free .glb food models on Sketchfab or Poly Pizza).
5.  Click **Save Item**.

### Generating QR Codes
1.  On the Dashboard, find your created item.
2.  Click the **"QR Code"** button.
3.  A dialog will appear with a generated QR code.
4.  **Important**: In local development, the QR code points to `localhost`. To test on your mobile, you need to replace `localhost` with your computer's local IP (e.g., `192.168.1.x`) or use a tunnel like `ngrok`.

---

## 3. User Experience (Customer)

### Viewing in AR
1.  Visit the URL generated by the QR code (e.g., `http://localhost:3000/view/[ITEM_ID]`).
2.  You will see the **Product Page** with the 3D model.
3.  **On Desktop**: You can rotate the 3D model with your mouse.
4.  **On Mobile**: Tap the **"View in AR"** button (bottom right of the viewer).
    *   This will open the mobile camera.
    *   Point it at a flat surface (table).
    *   The dish will appear in the real world!
